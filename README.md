# DoFollow

A micro extension that sets rel and target for in- and outside links.

The extension identifies the configured community URL, then sets:

| Link                                | Rel   | Target                |
|-------------------------------------|-------|-----------------------|
| Internal links to community         | _self | _blank                |
| External links outside of community | ugc   | noopener ugc nofollow |
